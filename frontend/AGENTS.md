# Vending Machine Frontend

This directory contains the Angular frontend for the VendingMachine project.

## Working In This Directory

- Keep frontend changes inside this directory unless a backend contract or root-level configuration must also change.
- Follow the existing Angular structure under `src/` and reuse the project's configured dependencies and scripts.
- Keep API integration consistent with the backend routes and response schemas.
- Do not add secrets or commit environment-specific values.

## Common Commands

Run these commands from this directory:

```cmd
npm start
npm test
npm run build
```

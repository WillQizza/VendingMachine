# Repository Guidance

This repository contains separate backend and frontend applications. Before making changes, read the guidance for the directory you are working in:

- Backend: [backend/AGENTS.md](backend/AGENTS.md) and [backend/CLAUDE.md](backend/CLAUDE.md)
- Frontend: [frontend/AGENTS.md](frontend/AGENTS.md) and [frontend/CLAUDE.md](frontend/CLAUDE.md)

Keep changes scoped to the relevant application and follow its existing structure, commands, and testing conventions.
